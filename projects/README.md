## Rules for external freight-forwarder communications

These rules apply to RFQs, emails, messages, and attachments sent outside Hungry Artisan.

1. **Never include internal PO numbers, invoice numbers, or internal PO/invoice details.** Justin explicitly instructed that these must not be included in external communications.
2. **Keep internal identifiers internal.** Do not put internal shipment references, internal cost/pricing details, or nonessential internal notes in a vendor-facing request. Use neutral labels such as **Shipment 1** and **Shipment 2** when a reference is needed.
3. **Share only the information needed to quote the shipment.** Provide verified cargo description, quantities, dimensions/CBM, gross weight, cargo-ready date, pickup location, destination, and cargo value only when relevant and confirmed.
4. **Do not guess missing details.** Verify against current supplier documents. If something is unknown, mark it pending internally and ask the supplier/provider for clarification before representing it as fact.
5. **Ask for comparable pricing.** Request DDP / delivered all-in and logistics-only itemized options where available. Require clear Incoterms, inclusions, exclusions, duties/taxes, customs, insurance, final-mile delivery, transit time, quote validity, and surcharges.
6. **A quote request is not a booking instruction.** State that the request is for evaluation/comparison only and does not authorize a booking or commit Hungry Artisan to award the shipment.
7. **Keep internal and external records separate.** Preserve internal PO/invoice/shipment references in approved internal records; share only the vendor-facing version externally.
8. **Protect accuracy and traceability.** Distinguish confirmed facts from estimates, assumptions, and unresolved questions. Save received quotations and update trackers only with actual, verified information.

## Before sending an RFQ

- [ ] Remove PO numbers, invoice numbers, and related internal details.
- [ ] Replace internal shipment IDs with a neutral label (e.g., Shipment 1 / Shipment 2).
- [ ] Confirm the latest supplier documents and all shipment details included in the message.
- [ ] Request itemized charges and clearly stated inclusions/exclusions.
- [ ] Confirm destination and routing assumptions, or label them as pending.
- [ ] Keep the wording quotation-only; do not imply booking approval.

**Working principle:** Understand the existing process, follow the confirmed rules, and make only the smallest useful improvement. The documents should support the workflow—not create extra administration.
