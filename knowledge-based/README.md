## How to use this folder

- **Check here before repeating research.** Reuse verified context and documented lessons where they still apply.
- **Keep facts current.** Confirm shipment-specific details against the latest supplier documents and operational records before using them externally.
- **Separate facts from assumptions.** Label estimates, open questions, and items awaiting confirmation clearly.
- **Protect internal information.** Follow company instructions for vendor communications; do not include internal PO numbers, invoice numbers/details, or unnecessary internal identifiers in external RFQs.
- **Keep documents focused.** Add knowledge to the relevant existing document when practical. Create a new document only when it serves a distinct, reusable purpose.
- **Link related material.** Connect relevant SOPs, project guides, and trackers rather than copying large sections into multiple places.
- **Do not treat historical data as automatic approval.** Verify current routes, pricing, shipment specifications, compliance requirements, and contacts before acting.

## Adding documents

When the folder grows, add new documents to the **Current documents** table above with a short description of what each one is for. A fuller table of contents and categories can be added later, when the number of documents makes that useful.

**Working principle:** Capture knowledge once, keep it trustworthy, and make it easy to reuse.
